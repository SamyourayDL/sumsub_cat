# Главная: статусы RETRY и FINAL

**Статус: Согласован.** 27 ноября 2026 пользователь подтвердил план словами
«Черновик подтверждаю». Согласованы жёлтая карточка RETRY с переходом в кабинет,
красная карточка FINAL, тексты и критерии приёмки ниже. Реализация передаётся
другому агенту.

## Результат

Главная `/` помогает понять, почему котик пока недоступен и можно ли что-то
сделать. Сейчас она показывает одну общую карточку для обоих исходов, хотя
личный кабинет их уже различает.

| Статус аккаунта | Предлагаемое оформление | Текст и действие |
| --- | --- | --- |
| `retry` (RED / RETRY) | Жёлтая карточка | **Нужно исправить материалы.** Продолжите проверку личности в личном кабинете. Кнопка **«Исправить материалы»** ведёт в `/account`. |
| `rejected` (RED / FINAL) | Красная карточка | **Проверка личности окончательно отклонена.** Доступ к мему закрыт для этого аккаунта. Личный кабинет доступен из навигации. |
| `approved` (GREEN) | Текущий экран с котиком | Котик и ссылка на личный кабинет. |
| Гость и остальные статусы | Текущая карточка | Общий текст и переход в личный кабинет. |

Для FINAL предложен текст про закрытый доступ для аккаунта. Слово «навсегда»
обещало бы больше, чем означает FINAL: при текущем решении пользователь
не может самостоятельно отправить материалы повторно.

## Реализация

1. В [обработчике главной](../../app/internal/web/meme.go) использовать статус,
   который сервер уже читает для пользователя из текущей сессии.
2. В [существующем шаблоне](../../app/internal/web/templates/page.html)
   добавить два визуальных варианта карточки. Заголовок и текст передают
   статус независимо от цвета. Использовать существующие HTML и CSS.
3. Сохранить действующие правила доступа к `/meme`, настройки кеширования и
   действия WebSDK в личном кабинете. Работа ограничена отображением `/`.
   Схема SQLite, webhook и зависимости сохраняются.

## Приёмка

- Для RETRY главная показывает жёлтое сообщение и переход в кабинет, где
  доступно существующее действие «Исправить материалы».
- Для FINAL главная показывает красное сообщение. Самостоятельная повторная
  подача остаётся недоступной.
- У гостя и аккаунта без результата сохраняется общая карточка. Одобренный
  аккаунт по-прежнему видит котика. Прямой `/meme` возвращает гостю `401`,
  аккаунтам RETRY и FINAL — `403`, одобренному аккаунту — `200`.
- Проверить переход в кабинет, читаемость карточек на узком экране и видимый
  фокус кнопки. Использовать временную SQLite и существующие проверки
  маршрутов в `app/internal/web`.
